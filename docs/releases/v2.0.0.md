# v2.0.0

## Stable OpenCode v2 support

`opencode-models-discovery@2.0.0` makes OpenCode v2 the primary and stable
integration. V2 uses the native `plugins` / `providers` configuration shape,
the provider lifecycle API, host-managed storage, Integration credentials, the
native TUI, RPC handlers, and Agent Tools.

## OpenCode v1 legacy support

The OpenCode v1 adapter remains available through the combined package
entrypoint. Existing V1 configuration, provider-level discovery settings, XDG
cache, auth fallback, and helper commands remain supported for compatibility,
security fixes, and severe regressions.

New lifecycle, cache, TUI, RPC, and model override features target OpenCode v2
first and are not automatically backported to V1.

## V2 model overrides

V2 model overrides are persisted in host storage under:

```text
overrides:<providerID>:<modelID>
```

Overrides can be listed, edited, enabled, disabled, and deleted through the V2
RPC contract and the `/models-discovery-console` model interaction. The model
list marks overridden models with `*`. Cache clearing does not delete overrides.

Supported fields include display name, limits, capabilities, reasoning,
attachments, variants, cost, and compatibility metadata. Credential and
authorization fields are rejected and are never persisted.

## Configuration

OpenCode v2 configuration uses:

```text
providers.<provider-id>.settings.modelsDiscovery
```

Example:

```json
{
  "plugins": ["opencode-models-discovery@2.0.0"],
  "providers": {
    "gateway": {
      "package": "@opencode-ai/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://gateway.example.com/v1",
        "modelsDiscovery": {
          "enabled": true,
          "cache": { "enabled": true, "ttlSeconds": 86400 }
        }
      }
    }
  }
}
```

Use `/connect` or a host environment substitution for credentials. V2 does not
read V1 `auth.json` or `OPENCODE_AUTH_CONTENT` fallback data.

## TUI and Agent Tools

Available V2 commands and tools include:

```text
/models-discovery-refresh
/models-discovery-console
models_discovery_refresh
models_discovery_status
```

The console supports model browsing, metadata inspection, cache operations, and
model override editing. Override changes reload the provider and refresh the
current TUI model list without restarting the service.

## Migration

V1 users can continue using the legacy adapter. Users moving to OpenCode v2
should follow [Migrating Configuration from OpenCode v1 to OpenCode v2](../migrate-v1-to-v2.md).

V1 XDG cache files are not imported into V2. V2 cache and override storage are
host-managed and use separate namespaces.

## Validation

This release is validated by the repository's V1/V2 unit and contract tests,
local OpenAI-compatible HTTP integration tests, compiled package checks, and
Node package-loadability tests.
